## Top Story
Claude's Auto Mode is now the default in Claude Code, and Boris Cherny (Claude Code lead) just posted on Threads that layering defenses—strong model alignment + prompt injection probes + Auto Mode—reduces prompt injection attack success rates to ~0%. This marks a critical shift: AI agent autonomy is becoming genuinely safer to deploy in production, which removes one of the last adoption barriers for SMBs building automation workflows.

This is the LinkedIn reputation angle: helping your audience see AI adoption as liberation, not threat.
